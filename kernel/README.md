# kernel/ —— 极简内核（零格式知识）

**唯一能力**（详见根 `CORE_MANIFEST.toml`，那是内核边界的唯一声明处）：

1. **调度**：进程/线程调度。
2. **协议/能力解释（路由）**：读取插件 manifest 的 `protocols`/`capabilities` 字段，把请求导向拥有该能力的插件。
3. **加载/隔离**：把插件装入隔离域。

**禁止**出现在本目录：文件系统格式、应用格式（ipa/exe/apk）、设备协议逻辑、UI、驱动。
格式兼容一律走 `plugins/compat/` 用户态兼容运行时；驱动也是插件（`plugins/builtin/`）。

> M0 阶段本目录只有本说明，无代码。M1 评估拉取 ToaruOS 底座（Misaka 为混合模块化内核——EtherOS 不追求纯微内核语义，以"用户态服务 + IPC + 可加载兼容运行时"体现插件化）。
